# Design

The interface has one job: get out of the way of the puzzle. A CTF is almost
entirely text and small pieces of generated data, so the design is mostly about
restraint — and about the handful of places where motion or colour genuinely
carries information.

- **[Foundations](foundations.md)** — the principles, the single-accent colour
  rule, and why the theme switch is CSS-driven rather than state-driven.
- **[Motion](motion.md)** — what animates and what deliberately does not, how
  disclosures animate their height without JavaScript, and the icon set.
- **[Components](components.md)** — the recurring patterns, the accessibility
  rules they follow, and the voice the copy is written in.

How the thing is built lives in [../architecture](../architecture/README.md).
